# Experiments

Store experiment implementations and artifacts here.

Recommended structure:

```text
experiments/
└── exp_XX_name/
    ├── README.md
    ├── config.*
    ├── run.*
    ├── raw/
    ├── processed/
    ├── figures/
    └── RESULTS.md
```

Experiment design is specified in `research/06_EXPERIMENT_CONTRACTS.md`.
