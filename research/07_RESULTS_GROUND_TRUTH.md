# Results Ground Truth

> **Purpose:** Researcher-approved, durable record of what the experiments actually establish.  
> **Authority:** This file outranks manuscript prose when they conflict.

> **Status scope:** Status values in this file apply only to this artifact type and are not equivalent to status values in other `research/` files.

## Rules

- Include only verified, researcher-approved scientific facts.
- Preserve scope and qualifications.
- Record negative/null results.
- Record important things **not established**.
- Link each statement to its evidence.
